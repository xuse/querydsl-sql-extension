# querydsl-sql-extension 编程指南

[querydsl-sql-extension](https://github.com/xuse/querydsl-sql-extension) 是基于 QueryDSL SQL 的增强框架，提供无反射高性能访问、注解驱动元数据、纯 POJO 模式（无需 Q 类）、Spring 集成等能力。

```xml
<dependency>
    <groupId>io.github.xuse</groupId>
    <artifactId>querydsl-sql-extension</artifactId>
    <version>5.0.0-r172</version>
</dependency>
<!-- Spring 集成（可选） -->
<dependency>
    <groupId>io.github.xuse</groupId>
    <artifactId>querydsl-sql-extension-spring</artifactId>
    <version>5.0.0-r172</version>
</dependency>
```

## 1. 初始化

**Spring 环境**

```java
@Bean
public com.github.xuse.querydsl.sql.SQLQueryFactory factory(DataSource ds) {
    return QueryDSLSqlExtension.createSpringQueryFactory(ds, querydslConfiguration());
}

private ConfigurationEx querydslConfiguration() {
    SQLTemplates templates = new MySQLWithJSONTemplates(); // 按数据库类型选择
    ConfigurationEx configuration = new ConfigurationEx(templates);
    configuration.addListener(new QueryDSLSQLListener(QueryDSLSQLListener.FORMAT_DEBUG));
    configuration.addListener(new UpdateDeleteProtectListener()); // 防全表 UPDATE/DELETE
    configuration.setSlowSqlWarnMillis(200);
    configuration.scanPackages("com.example.entity"); // @CustomType 等注解需要包扫描才生效
    return configuration;
}
```

**非 Spring 环境**

```java
ConfigurationEx configuration = new ConfigurationEx(SQLQueryFactory.calcSQLTemplate(jdbcUrl));
configuration.addListener(new QueryDSLSQLListener(QueryDSLSQLListener.FORMAT_COMPACT));
SQLQueryFactory factory = new SQLQueryFactory(configuration, dataSource, true);
```

> SQLQueryFactory 是线程安全的，作为单例使用。生产环境日志用 FORMAT_COMPACT。

## 2. 实体定义

直接在 POJO 上加注解，无需生成 Q 类：

```java
@Data
@TableSpec(name = "user_info", primaryKeys = "id",
    keys = { @Key(path = {"email"}, type = ConstraintType.UNIQUE) })
@Comment("用户信息表")
public class UserInfo {

    @ColumnSpec(autoIncrement = true, unsigned = true, nullable = false)
    private int id;

    @ColumnSpec(size = 64, nullable = false)
    private String name;

    @ColumnSpec(size = 128, nullable = false, defaultValue = "''")
    private String email;

    @AutoGenerated(GeneratedType.CREATED_TIMESTAMP)
    private Date created;

    @AutoGenerated(GeneratedType.UPDATED_TIMESTAMP)
    private Date updated;

    // NOT NULL 列用原始类型，配合 @UnsavedValue 避免默认值歧义
    @UnsavedValue(UnsavedValue.ZeroAndMinus)
    @ColumnSpec(nullable = false, defaultValue = "0")
    private int status;
}
```

**常用注解速查**

| 注解 | 位置 | 用途 |
|------|------|------|
| `@TableSpec` | 类 | 表名、主键、索引、约束 |
| `@ColumnSpec` | 字段 | 列名、类型、长度、nullable、默认值、自增 |
| `@Comment` | 类/字段 | 表或列注释 |
| `@AutoGenerated` | 字段 | 自动填充（`CREATED_TIMESTAMP` / `UPDATED_TIMESTAMP` / `SNOWFLAKE`） |
| `@UnsavedValue` | 字段 | 原始类型无效值判定（`ZeroAndMinus` / `Zero` / `MinusNumber`） |
| `@CustomType` | 字段 | 自定义序列化（需包扫描），如 JSON、加密、枚举映射 |

**@CustomType 示例**

```java
@CustomType(JSONObjectType.class)           // JSON 序列化存储
private MyObject data;

@CustomType(AESEncryptedField.class)        // AES 加密存储
private String phone;

@CustomType(EnumByCodeType.class)           // 枚举按编码存储
private Gender gender;
```

## 3. CRUD 操作

### 3.1 Repository 风格（推荐日常业务使用）

```java
CRUDRepository<UserInfo, Integer> repo = factory.asRepository(() -> UserInfo.class);
```

**基本操作**

```java
repo.insert(user);
repo.insertBatch(userList);
UserInfo user = repo.load(1);                          // 按主键查
List<UserInfo> users = repo.loadBatch(Arrays.asList(1, 2, 3));
repo.update(1, user);                                  // 按主键更新
repo.delete(1);                                        // 按主键删除
```

**Lambda 查询**

```java
List<UserInfo> list = repo.query()
    .eq(UserInfo::getName, "John")
    .between(UserInfo::getCreated, startTime, endTime)
    .orderByAsc(UserInfo::getId)
    .fetch();

// 分页（返回总数 + 数据）
Pair<Integer, List<UserInfo>> page = repo.query()
    .eq(UserInfo::getStatus, 1)
    .findAndCount(20, 0);  // limit, offset
```

**@ConditionBean 查询（Web 分页场景）**

```java
@Data
@ConditionBean(limitField = "limit", offsetField = "offset")
public class UserQuery {
    @Condition(Ops.STRING_CONTAINS)
    private String name;           // LIKE '%name%'

    @Condition(Ops.BETWEEN)
    private Date[] created;        // created BETWEEN ? AND ?

    @Condition(Ops.EQ)
    private Integer status;        // status = ?

    private Integer limit;
    private Integer offset;
}

// 空字段自动忽略，不作为 WHERE 条件
UserQuery params = new UserQuery();
params.setName("John");
params.setLimit(20);
Pair<Integer, List<UserInfo>> result = factory.findByCondition(params);
```

### 3.2 SQLQueryFactory 风格（复杂查询 / 多表关联）

需要 Q 类。Q 类继承 `RelationalPathBaseEx`，构造器中调用 `scanClassMetadata()`。

```java
QUserInfo t = QUserInfo.userInfo;

// 插入并获取自增主键
Integer id = factory.insert(t).populate(bean).executeWithKey(Integer.class);

// 查询
UserInfo user = factory.selectFrom(t).where(t.id.eq(id)).fetchOne();

// 更新
factory.update(t)
    .set(t.name, "Jane")
    .set(t.updated, Expressions.currentTimestamp())
    .where(t.id.eq(id))
    .execute();

// 差异更新（仅 SET 变化的字段，无变化则不执行）
factory.update(t).populateWithCompare(newBean, oldBean).where(t.id.eq(id)).execute();

// 删除
factory.delete(t).where(t.id.eq(id)).execute();

// 多表关联
QDepartment t2 = QDepartment.department;
List<Tuple> rows = factory.select(t.name, t2.deptName)
    .from(t).innerJoin(t2).on(t.deptId.eq(t2.id))
    .where(t.status.eq(1))
    .fetch();
```

**大数据量查询调优**

```java
List<Integer> ids = factory.select(t.id).from(t)
    .setFetchSize(10000)
    .setMaxRows(1_000_000)
    .setQueryTimeout(15)
    .fetch();
```

## 4. 自定义 Repository

```java
@Repository
public class UserRepository extends GenericRepository<UserInfo, Integer> {
    // 继承后自动拥有 load/insert/update/delete/query 等方法
    // 下面添加业务特定方法

    public List<UserInfo> findActiveByDept(int deptId) {
        QUserInfo t = QUserInfo.userInfo;
        return getFactory().selectFrom(t)
            .where(t.status.eq(1).and(t.deptId.eq(deptId)))
            .orderBy(t.created.desc())
            .fetch();
    }
}
```

## 5. 从数据库生成实体映射

需要额外引入 codegen 模块：

```xml
<dependency>
    <groupId>io.github.xuse</groupId>
    <artifactId>querydsl-sql-extension-codegen</artifactId>
    <version>5.0.0-r172</version>
</dependency>
```

**生成代码**

```java
import io.github.xuse.querydsl.sql.code.generate.DbSchemaGenerator;
import io.github.xuse.querydsl.sql.code.generate.model.OutputDir;
import io.github.xuse.querydsl.sql.code.generate.model.MetafieldGenerationType;

DataSource ds = createDataSource(); // 使用用户提供的 JDBC 连接信息创建
DbSchemaGenerator.from(ds)
    .packageName("com.example.entity")              // 生成类的包名
    .output(OutputDir.DIR_MAIN)                     // 输出到 src/main/java/
    .metafields(MetafieldGenerationType.LAMBDA)     // NONE=纯POJO / QCLASS=生成Q类 / LAMBDA=静态列引用
    .useLombokAnnotation(true)                      // 使用 @Data 注解
    .overwriteFiles(false)                          // 不覆盖已有文件
    .generateTables(null, "%");                     // null=当前库, "%"=所有表
```

**API 说明**

| 方法 | 用途 |
|------|------|
| `packageName(String)` | 生成类的 Java 包名 |
| `output(OutputDir)` | 输出目录：`DIR_MAIN`(src/main/java)、`DIR_TEST`(src/test/java)、`DIR_TARGET`(target/generated-sources) |
| `metafields(MetafieldGenerationType)` | `NONE`=仅 POJO，`QCLASS`=生成 Q 类，`LAMBDA`=在 POJO 中生成静态列引用常量 |
| `useLombokAnnotation(boolean)` | 是否使用 Lombok `@Data` |
| `overwriteFiles(boolean)` | 是否覆盖已有文件 |
| `generateTable(String)` | 生成单张表 |
| `generateTables(namespace, pattern)` | 按模式匹配生成，如 `"user%"` 生成 user 开头的表 |
| `generateAll(databaseName)` | 生成整个库/Schema 的所有表 |
| `autoFieldOfCreateTime(String...)` | 自动识别为创建时间的字段名（默认 created, createTime） |
| `autoFieldOfUpdateTime(String...)` | 自动识别为更新时间的字段名（默认 updated, updateTime） |

## 交互场景

### 场景：用户希望从数据库生成实体映射

当用户表达"生成数据库映射"、"从数据库生成实体"、"生成表对应的 Java 类"等意图时，按以下流程操作：

1. **收集连接信息**：向用户询问以下信息（如未提供）：
   - JDBC URL（如 `jdbc:mysql://localhost:3306/mydb`）
   - 数据库用户名
   - 数据库密码
   - 要生成的表（全部表 or 指定表名/模式）

2. **确定输出位置**：
   - 检查当前工程的 Maven 模块结构，找到合适的实体包路径
   - 如果工程中已有实体类，使用相同的包名
   - 如果没有，建议使用 `{项目基础包}.entity` 作为包名
   - 确认输出到 `src/main/java/` 下

3. **确定生成选项**：
   - 默认使用 `MetafieldGenerationType.LAMBDA`（纯 POJO + 静态列引用）
   - 默认启用 Lombok
   - 默认不覆盖已有文件

4. **生成代码**：在工程的 `src/test/java` 下创建一个一次性的生成器类并运行：

```java
public class CodeGenerator {
    public static void main(String[] args) {
        HikariDataSource ds = new HikariDataSource();
        ds.setJdbcUrl("{用户提供的 JDBC URL}");
        ds.setUsername("{用户提供的用户名}");
        ds.setPassword("{用户提供的密码}");

        DbSchemaGenerator.from(ds)
            .packageName("{确定的包名}")
            .output(OutputDir.DIR_MAIN)
            .metafields(MetafieldGenerationType.LAMBDA)
            .useLombokAnnotation(true)
            .overwriteFiles(false)
            .generateTables(null, "%");

        ds.close();
    }
}
```

5. **后续引导**：生成完成后，提醒用户：
   - 检查生成的实体类，按需调整字段类型和注解
   - 确保 `ConfigurationEx.scanPackages()` 包含生成类的包路径
   - 如果工程 pom.xml 中尚未引入 `querydsl-sql-extension`，协助添加依赖

## 代码生成规则

1. 优先纯 POJO + Lambda 风格，除非用户要求 Q 类
2. 初始化必须包含 `scanPackages()`，否则 `@CustomType` 等注解不生效
3. Spring 项目用 `QueryDSLSqlExtension.createSpringQueryFactory()` 初始化
4. NOT NULL 列映射原始类型，配合 `@UnsavedValue`
5. SQLQueryFactory 作为单例，不要每次请求创建
