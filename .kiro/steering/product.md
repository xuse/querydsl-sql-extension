# Product Overview

querydsl-sql-extension is a Java library that extends [QueryDSL SQL](https://github.com/querydsl/querydsl) with higher performance and richer features. It is published to Maven Central under group `io.github.xuse`.

## Core Value Propositions

- **High-performance JDBC access** — ASM-generated accessors eliminate reflection; batch insert/select can be 3-8x faster than MyBatis in benchmarks.
- **Annotation-driven metadata** — `@TableSpec`, `@ColumnSpec`, `@CustomType`, `@AutoGenerated` let developers define full table schemas in Java, enabling metadata-first DDL generation.
- **Pure POJO mode** — operate the database without generating Q-classes; use lambda expressions for column references.
- **DDL management** — create, alter, and diff database schemas from Java models. Full support for MySQL, PostgreSQL, Derby, H2; type mappings and DDL templates for Oracle, SQL Server, HSQLDB, SQLite, DB2, CUBRID.
- **R2DBC support** — reactive, non-blocking database access via dedicated modules.
- **Spring integration** — optional module for Spring transaction management and `GenericRepository`.

## Supported Databases

DML: MySQL, PostgreSQL, Oracle, DB2, Derby, H2, HSQLDB, SQLite, SQL Server, CUBRID, Firebird, Teradata.
DDL: MySQL 5.6+, PostgreSQL 10.3+, Derby 10.14+, H2 2.3+ (full); Oracle, SQL Server 2005/2008/2012+, HSQLDB, SQLite, DB2, CUBRID (type mappings and DDL templates).

## Versioning

Format: `v{querydsl-version}-r{extension-revision}` (e.g. `5.0.0-r172`). The first part tracks the upstream QueryDSL version.
